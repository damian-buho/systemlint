# Швидкий збір лише для читання

- Збирачі працюють паралельно, тож повна перевірка досить швидка для кожного завантаження, розгортання й завдання CI. Див. [збирачі](../how-to/collectors.md).
- Збір лише читає: кожен файл, команда й відповідь мають обмеження розміру та часу, тож завислий монтований ресурс чи величезний файл ніколи не зупинить запуск.
- З `--root` символьні посилання образу розв’язуються всередині образу, тож перевірка недовіреного образу ніколи не читає файли хоста.
