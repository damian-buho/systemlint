# Виправлення, які він робить сам, і лише ті, що забирають доступ

- `systemlint fix` вносить зміни, які звіт друкує рядками `Run:`, на живому хості або в кореневій файловій системі образу з `--root`, і спершу питає. Див. [виправлення](../how-to/rules.md#remedies).
- Виправлення лише забирає доступ: знімає біти дозволів, віддає файл root або коментує рядок, що надає доступ, тож набір правил, якого ви не писали, ніколи не передасть файл користувачеві.
- Рядок, змінений після перевірки, залишається недоторканим, а єдиний авторизований ключ облікового запису зберігається, тож виправлення ніколи не позбавить вас доступу.
- Два джерела apt, що дублюють одне одне, показано як одну проблему з одним виправленням, а не як дві знахідки.
