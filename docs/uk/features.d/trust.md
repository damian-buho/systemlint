# Безпечно запускати від root на хості, якому ви не довіряєте

- Кожен шлях читають усередині кореня, що перевіряється, тож символьне посилання в недовіреному образі ніколи не змусить сканування читати власні файли хоста.
- Кожен плагін — окрема статична програма, що лише перетворює байти, прочитані ядром, на факти: вона не відкриває файлів, не запускає команд і не торкається мережі. Див. [протокол](../how-to/protocol.md).
- Плагіни, збирачі та набори правил завантажують лише з каталогів, що належать root або вам і доступні для запису нікому іншому, а збирач, записаний просто у файлі конфігурації, не може запускати команду.
- Ніщо не залишає хост, доки цього не попросить `--network`.
