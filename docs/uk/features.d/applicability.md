# Правила, які знають, для яких хостів вони написані

- Набір правил називає хости, для яких його написано, тож на будь-якому іншому хості його правила відповідають «не застосовується», ніколи «невідомо» чи «порушено», і не впливають на рейтинг. Див. [правила](../how-to/rules.md).
- Вбудовані правила apt оцінюють Debian, Ubuntu та дистрибутиви на їхній основі, а на всіх інших хостах не застосовуються. Див. [джерела apt](../how-to/apt.md).
- Процедура, яку не доводить жоден факт, — це ручне правило: його показано людині для перевірки й ніколи не зараховано як пройдене.
- Стандарт, до якого не застосовується жодне з його правил, відповідає «не застосовується», а стандарт із ручними контролями каже, скільки з них ще має перевірити людина.
