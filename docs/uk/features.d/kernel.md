# Захист ядра та процесора за звітом працюючого ядра

- Вади процесора, які працююче ядро повідомляє як не пом’якшені, і налаштування ядра, що віддають непривілейованим користувачам розкладку пам’яті, адреси ядра чи додаткову поверхню атаки, — кожне є знахідкою.
- Модулі ядра для рідкісних файлових систем, протоколів і пристроїв, що завантажуються на вимогу, знаходять серед модулів, постачених для кожного встановленого ядра, а контролер USB, що довіряє кожному новому пристрою, повідомляють. Див. [модулі ядра](../how-to/services.md#kernel-modules).
- Правила аудиту оцінюють за тим, що вони записують, на диску й завантажені, а не за написанням одного стандарту, тож рівнозначне правило, записане інакше, проходить. Див. [правила аудиту ядра](../how-to/services.md#kernel-audit-rules).
- Незавантажений AppArmor, меню GRUB, яке може редагувати будь-хто, аварійна оболонка без пароля та дампи пам’яті привілейованих програм — кожне є знахідкою.
