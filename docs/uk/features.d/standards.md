# Правила, що посилаються на стандарти, яким вони відповідають

- Кожне правило має тегами контролі, яким воно відповідає, тож `--tags 'cis-ubuntu-26.04:5.2.*'` запускає один стандарт або один його розділ. Див. [правила](../how-to/rules.md).
- Там, де два стандарти суперечать один одному, як примусова зміна паролів проти NIST SP 800-63B, запуск повідомляє один конфлікт і не провалює хост за жодною з них, а `--tags all --prefer 'cis-ubuntu-26.04:*'` запускає всі правила, де кожен конфлікт виграє цей стандарт. Див. [суперечливі стандарти](../how-to/rule-book.md#conflicting-standards).
- Поріг, який обирає стандарт, за замовчуванням дорівнює числу цього стандарту й змінюється через `--var`, тож дотримання власної політики не потребує власного правила.
